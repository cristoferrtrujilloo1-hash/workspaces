# 🍲 GourmetLedger &bull; Control Profesional de Créditos y Cobranza para Comida

Sistema web con diseño ejecutivo, ágil y moderno (POS & Fintech) diseñado específicamente para fondas, restaurantes, comedores, taquerías y negocios de comida que necesitan llevar el control exacto de las personas a las que les fían y generar comprobantes y reportes automáticos para cobrarles en **Quetzales (Q.)**.

## 🚀 ¿Cómo abrir la aplicación?

1. Dirígete a la carpeta del proyecto:
   `C:\Users\SISTEMAS\.gemini\antigravity\scratch\control-creditos-comida`
2. Haz **doble clic** sobre el archivo [**`index.html`**](file:///C:/Users/SISTEMAS/.gemini/antigravity/scratch/control-creditos-comida/index.html).
3. Se abrirá de inmediato en cualquier navegador web (Google Chrome, Microsoft Edge, Brave, etc.).
4. **100% Autónomo y Offline**: No requiere instalar programas adicionales ni conexión a internet. Todos los datos se guardan de forma privada en tu equipo.

## 💎 Novedades del Nuevo Diseño Profesional

1. **Tablero Ejecutivo (KPI Cards)**:
   - **Total por Cobrar (Deuda Activa)** con conteo en vivo de deudores.
   - **Total Recaudado (Cobrado)** acumulado.
   - **Ticket Promedio de Crédito** por comensal deudor.
   - Indicador de estado de la base de datos local.

2. **Doble Vista de Comensales (Tarjetas y Tabla Ejecutiva)**:
   - **Vista de Tarjetas**: Avatares con iniciales por color, barra de progreso de límite de crédito, atajos rápidos de fiado/abono y botones destacados para cobrar.
   - **Vista Tabla Ejecutiva**: Ideal para pantallas de escritorio, permite revisar decenas de clientes como en una hoja contable rápida.

3. **Iconografía SVG Vectorial Nativa**:
   - Reemplazo total de emojis por iconos profesionales limpios, elegantes y nítidos.

4. **Ticket Térmico POS Auténtico (80mm) y Estado de Cuenta Formal**:
   - Formato visual de ticket de restaurante con corte dentado, tipografía monoespaciada para números contables, desglose por fecha/hora y cuentas bancarias listas para transferencias.

5. **Notificaciones Flotantes (Toasts)**:
   - Alertas sutiles y elegantes para confirmaciones de cobro, abonos y guardado.

6. **Exportación Nativa a Excel (.XLS con Columnas y Formato)**:
   - Generación de hojas de cálculo `.xls` que abren directamente en Microsoft Excel sin mezclar el texto en una sola columna.
   - Columnas con anchos proporcionales, encabezados en azul marino, números con formato de moneda en Quetzales y totales consolidados.
